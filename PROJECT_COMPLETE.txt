🎯 使い方（デイリー・ルーチン）
------------------------------------------------------------
1. 【発動】: Ctrl + Shift + E
   -> 十字カーソルで範囲を選択する。
2. 【完了】: 数秒待つと通知が出る。
3. 【展開】: ChatGPT / Cursor / VS Code 等で Ctrl + V。

------------------------------------------------------------
🎮 司令塔（ダッシュボード）
------------------------------------------------------------
設定を変えたい、APIをチェックしたい時はアイコンを叩くか以下を実行：
  $ ./.venv-ocr27/bin/python ocr_dashboard.py

  - [⚙️ 設定]: 前文(Prefix)・後文(Suffix)をGUIで書き換え。
  - [🔗 API]: Google Cloud Consoleへ一蹴。
  - [📸 手動]: 動作テスト用のOCR起動。

------------------------------------------------------------
🛠️ 困った時の診断（セルフチェック）
------------------------------------------------------------
何も起きない、ログが止まった、そんな時はこの呪文を唱えろ：
  $ ./.venv-ocr27/bin/python preflight_check.py

  - 全て ✅ なら正常。OSのキー競合（IBus等）を疑え。
  - ❌ があれば、その項目の指示に従え。

------------------------------------------------------------
📂 主要なファイルと役割
------------------------------------------------------------
- scan_clipboard.py  : システムの心臓。OCRと合成を司る。
- config_gui.py      : プロンプト（人格）を編集するGUI。
- config.json        : あなたが設定したプロンプトの貯蔵庫。
- ocr_debug.log      : 裏側で何が起きたかの全記録。
